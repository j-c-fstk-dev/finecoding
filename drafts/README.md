## How to update a post in the dashboard

1. Open the existing post in the dashboard (Edit).
2. **Title** and **Excerpt**: copy from the `title:` / `excerpt:` lines (without quotes).
3. **Content**: paste everything after the second `---`.
4. **Tags**: optional, from the `tags:` line.
