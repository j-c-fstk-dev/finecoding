# Fine Coding 2.0: visual prototype

Static HTML mockup for the blog redesign: the structure of linear.app/now
(thin header, big title with category tabs and search, 3-column grid with
divider lines, centered article with a narrow reading column) restyled as a
green phosphor terminal.

Open `index.html` (post list) and `article.html` (article page) in a browser.
Screenshots are in `screenshots/`.

- Fonts: Inter (UI and reading) + JetBrains Mono (labels, meta, code), both
  under the SIL Open Font License, from Fontsource.
- Covers are generated SVG line art (`covers.js`), one motif per post.
- Not wired to the app yet: this is for deciding the direction before
  changing the real components.
